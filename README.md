## 🚀 Featured Project

### 🔍 [react-click-inspector](https://github.com/NezerAbdullayev/react-click-inspector)

A lightweight React component to detect clicks outside of any specified element.  
Perfect for handling dropdowns, modals, and custom context menus in your applications.

- 📦 [View on npm](https://www.npmjs.com/package/react-click-inspector)
- 💻 [Source Code](https://github.com/NezerAbdullayev/react-click-inspector)

### 🤖 [robot](https://github.com/NezerAbdullayev/robot)

An AI-powered robot for TikTok live streams. It reads live comments, replies using Gemini AI with text-to-speech (edge-tts),
reacts to gifts and follows, greets new viewers by name, and can record its answers as TikTok-ready MP4 videos.

- 💻 [Source Code](https://github.com/NezerAbdullayev/robot)

### 🧪 [API Lens](https://github.com/NezerAbdullayev/qa_extention)

A Chrome extension (Manifest V3) for QA and developers. It captures every network request in a tab (URL, headers, payload, response, status, errors),
exports them as HAR, saves snapshots, and shows the differences between two snapshots. Built with React, TypeScript, Vite and Tailwind CSS.

- 💻 [Source Code](https://github.com/NezerAbdullayev/qa_extention)
